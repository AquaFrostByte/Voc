# Voc to CSV

It's a simple website that can export your Vocab into an Excel file. I personally use it to digitise my stuff.

## Why do i make this project and how is it usefull?

I like to learn vocab over NotebookLLM. Sadly uploading it as an image sucks, words are missing or just wrong.
So i type them by hand into Exel... Its really not efficiant.
So I have this website now, It lets u just type them in real fast and get the .csv for to get it easyer into an ai or other learning programs.

Nothing pretty much...
