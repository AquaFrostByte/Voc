# Vocabulary Digitizer!

This is my small little Website to digitize ur Vocabulary!
Its there so u can digitize Vocabulary fastly and easily. :3

## How does it work?

### Its pretty simple:
1 U open up the side
2 U type in Ur Words u can either just write the words or Word and translation
3 Hit enter and its added to the list!

### Other Features include:

1 Importing already existing CSV/ Vocabulary lists
2 Download the CSV/ Vocabulary list
3 Copy it to be pasted into Google Sheets
4 Adding Chapters for different Units for example
5 A light mode for psychos like me
6 A resources tab to help a bit if u start out with language learning!
